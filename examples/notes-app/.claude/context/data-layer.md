# Data layer

> **Read this when:** the change touches what a note looks like *in storage*, the guard that vets it, the browser-storage gateway, or a storage constant — anything under `src/data`. **Skip when:** the change is a business rule, a conversion between the stored shape and the entity, or anything on screen: those are `src/domain` and `src/presentation`, and each has its own file. Read `.claude/context/conventions.md` first either way.

**Purpose.** The persisted shape of a note, the gateway that moves it in and out of the browser, and how little of that the rest of the codebase is allowed to see.

## The persisted shape

- **`NoteRecord` (`src/data/noteRecord.ts`) is the serialized shape, and it holds only what JSON can carry** — strings, numbers, booleans. A time is epoch milliseconds, `createdAt` and `updatedAt` alike; a `Date`, a `Map`, a `Set` or a class instance in this interface is a defect, because it survives `JSON.stringify` as something `JSON.parse` will not give back. _(read off: `src/data/noteRecord.ts` (`NoteRecord`, `createdAt`, `updatedAt`))_
- **A field a stored record may predate is declared optional, and what its absence means is a named exported constant beside the interface** — `PINNED_WHEN_ABSENT`, `UPDATED_AT_WHEN_ABSENT`. Declaring it required makes `isNoteRecord` reject every record already in the browser and `readAll` drop them without a word. The constant's **name shape** is owned by `.claude/context/conventions.md` (`## The layers, and the direction a dependency may point`); what this layer decides is which field is optional, and what its absence means. _(read off: `src/data/noteRecord.ts` (`NoteRecord`, `PINNED_WHEN_ABSENT`, `UPDATED_AT_WHEN_ABSENT`))_
- **The constant's value is the state the absence *is*, never a substitute borrowed from another field.** `PINNED_WHEN_ABSENT` is `false` because not-pinned is a real value of that field; `UPDATED_AT_WHEN_ABSENT` is `null` because never-edited is a real state with no instant behind it, and `createdAt` is explicitly not a fallback — creating a note is not an edit of it. The two records that resolve to one such constant — one written before the field existed, one whose note genuinely never reached the state — are stated to be the same single state rather than two. _(read off: `src/data/noteRecord.ts` (`UPDATED_AT_WHEN_ABSENT`, `PINNED_WHEN_ABSENT`), which states both in prose)_
- **Every interface in this layer gets a runtime guard named `is<TypeName>`, returning `value is <TypeName>` over an `unknown` parameter**, and the guard is exported beside the interface it vets. A type with no guard cannot be read back safely, because storage returns untyped input whoever wrote it. _(read off: `src/data/noteRecord.ts` (`isNoteRecord`))_
- **A guard checks every required field for type *and* for usability, and accepts an optional field only as `undefined` or as its declared type, vetted as strictly as a required one.** `isNoteRecord` rejects an empty `id` and a non-finite `createdAt`, not merely a wrong `typeof`; the `pinned` clause is `candidate.pinned === undefined || typeof candidate.pinned === 'boolean'`, and the `updatedAt` clause pairs `typeof … === 'number'` with `Number.isFinite(…)` behind the same `undefined` alternative — an optional number gets `createdAt`'s pair, not half of it. _(read off: `src/data/noteRecord.ts` (`isNoteRecord`))_
- **An optional field says why it may be absent in two places: the interface's doc comment, and a comment on its own clause in the guard.** Optionality here is a compatibility decision rather than a shrug, and the next reader of the guard is deciding whether to tighten the clause. _(read off: `src/data/noteRecord.ts` (`NoteRecord`, `isNoteRecord`))_
- **The one type assertion this layer permits is the widening to an index type inside a guard, after the `object`-and-not-`null` check** — `value as Record<string, unknown>`. Asserting straight to the target type, or reaching for `any`, deletes the check the guard exists to perform. _(read off: `src/data/noteRecord.ts` (`isNoteRecord`))_
- **The storage key lives in `src/data/noteRecord.ts` and is exported: `NOTES_STORAGE_KEY` is never re-spelled as a literal at a use site under `src/`.** `src/data/noteRecord.ts` is the only file that spells its value; a second key introduced anywhere else is a decision to state here, not one a task makes. The rule is about the **key**, and it does not reach the values the absence constants name: a case asserts what `PINNED_WHEN_ABSENT` or `UPDATED_AT_WHEN_ABSENT` means as a literal rather than importing the constant, which is `.claude/context/tests.md` (`## What a case may reach`)'s to own and is the opposite claim — the key is an identifier a test does not care about, the default is the behaviour it is about. _(read off: `src/data/noteRecord.ts` (`NOTES_STORAGE_KEY`), `src/data/notesStore.ts` (`readAll`, `writeAll`), `.claude/context/tests.md` (`## What a case may reach`))_
- **A serialized field is named exactly as the entity property it corresponds to, and the two differ by type only.** The rule and its rationale belong to `.claude/context/conventions.md` (`## The wire surface`); the consequence here is that a new `NoteRecord` field is named for the `Note` property, never abbreviated or snake_cased on its way to disk. _(read off: `src/data/noteRecord.ts` (`NoteRecord`), `.claude/context/conventions.md` (`## The wire surface`))_

## The gateway, and what it may do

- **A read or write of browser storage is a function in `src/data/notesStore.ts` and is reached through `globalThis.localStorage` at call time, never through a module-scope binding captured at import.** A module-level `const storage = localStorage` runs before a test installs its double and before the page has a global to capture. The cross-layer prohibition on any other file touching `localStorage` is owned by `.claude/context/conventions.md` (`## The layers, and the direction a dependency may point`). _(read off: `src/data/notesStore.ts` (`readAll`, `writeAll`))_
- **The gateway returns the stored collection whole, in stored order.** It takes no filter, no sort key and no limit: selecting and ordering are domain work, and a filter parameter here would put the same predicate in two layers. `readAll()` therefore has no parameters, and a caller that wants a subset filters what it gets. _(read off: `src/data/notesStore.ts` (`readAll`), `src/domain/notesService.ts` (`listNotes`))_
- **A write replaces the whole collection.** `writeAll(records)` takes the full list and serializes it in one `setItem`. Writes stay collection-wide: a per-item write path would make the persisted order depend on call order rather than on the array the caller holds. _(read off: `src/data/notesStore.ts` (`writeAll`), `src/domain/notesService.ts` (`update`))_
- **An element that fails the guard is dropped; an element that passes it is returned untouched.** `readAll` ends in `parsed.filter(isNoteRecord)` and touches nothing it keeps. That a record read back is never repaired on the way in is owned by `.claude/context/conventions.md` (`## The wire surface`); resolving an absence is the mapper's, and doing it here would hide from the caller that the key was never written. _(read off: `src/data/notesStore.ts` (`readAll`), `test/notesStore.test.mjs` (`'readAll keeps a record written before updatedAt existed and leaves the key absent'`), `.claude/context/conventions.md` (`## The wire surface`))_
- **Every call re-reads from storage: this layer keeps no cached copy of what it read and notifies nobody when it writes.** A module-scope cache, a subscription or an event emitter added here is a decision to state rather than a task's to make. Which store is the source of truth, and how the surface refreshes from it, is owned by `.claude/context/conventions.md` (`## State, and where the truth lives`). _(read off: `src/data/notesStore.ts` (`readAll`), `.claude/context/conventions.md` (`## State, and where the truth lives`))_
- **A record arrives with its identifier and every timestamp already set by its caller: this layer generates neither.** `crypto.randomUUID()` and `new Date()` are the domain's — `id` and `createdAt` in `src/domain/notesService.ts` (`addNote`), the `updatedAt` stamp in `editNote`. Generating either here would make a stored record untestable without freezing time. _(read off: `src/data/notesStore.ts` (`writeAll`), `src/domain/notesService.ts` (`addNote`, `editNote`))_

## Failure, as a caller sees it

- **A malformed read is absorbed and a failed write is raised.** `readAll` returns `[]` for an absent key, unparseable JSON or a stored value that is not an array, and drops the individual elements that fail the guard while their well-formed siblings survive; `writeAll` throws. A read that throws would make one corrupt element cost the user every note. _(read off: `src/data/notesStore.ts` (`readAll`, `writeAll`), `test/notesStore.test.mjs` (`'readAll drops a record failing the guard and keeps its siblings'`))_
- **A write failure surfaces as this layer's own error class, `StorageWriteError`, carrying the platform failure as `cause`** — `new StorageWriteError(message, { cause })` — and the class sets `this.name` to its own name in the constructor. A caller distinguishes a storage failure from a domain rejection by class, never by message text. The rule that a layer raising an error a caller may distinguish defines its own named class is owned by `.claude/context/conventions.md` (`## Errors and logging`). _(read off: `src/data/notesStore.ts` (`StorageWriteError`, `writeAll`), `test/notesStore.test.mjs` (`error.cause === quota`))_
- **The message names what failed to persist and where, and is lower-case, unpunctuated and free of user-facing wording:** `` could not persist ${records.length} note(s) to '${NOTES_STORAGE_KEY}' ``. What the user is told is the surface's to decide. _(read off: `src/data/notesStore.ts` (`writeAll`))_
- **This layer reports failure by throwing and by no other means.** The project-wide absence of a logger is owned by `.claude/context/conventions.md` (`## Errors and logging`). _(read off: `src/data/notesStore.ts` (`readAll`, `writeAll`))_

## What this layer may import, and who maps its types

- **A module under `src/data/` imports only sibling modules under `src/data/`.** `src/data/notesStore.ts` imports `./noteRecord.js`; an import of `../domain/` or `../presentation/` is a defect however small. The inward-only direction is owned by `.claude/context/conventions.md` (`## The layers, and the direction a dependency may point`). _(read off: `src/data/notesStore.ts` (`import { NOTES_STORAGE_KEY, isNoteRecord, type NoteRecord }`), `src/data/noteRecord.ts` (file header))_
- **The conversion between `NoteRecord` and `Note` belongs to `src/domain/noteMapper.ts`, in both directions, and never runs here.** This layer does not know the entity type exists. The resolution of an absent optional field — `record.pinned ?? PINNED_WHEN_ABSENT`, and the `undefined` test that yields `UPDATED_AT_WHEN_ABSENT` — happens in the mapper; this layer only *names* the default. What `toRecord` writes back for such a field is owned by `.claude/context/conventions.md` (`## The wire surface`). _(read off: `src/domain/noteMapper.ts` (`toNote`, `toRecord`), `src/data/noteRecord.ts` (`PINNED_WHEN_ABSENT`, `UPDATED_AT_WHEN_ABSENT`))_

## Adding to this layer

- **A new persisted field** is a field on `NoteRecord`, a clause in `isNoteRecord`, and — when existing records may lack it — an optional declaration plus the constant naming what its absence means, whose value this layer decides. The order the rest of the change follows is owned by `.claude/context/conventions.md` (`## How a change flows, and the order files are created in`), which starts here. _(read off: `src/data/noteRecord.ts` (`NoteRecord`, `isNoteRecord`, `UPDATED_AT_WHEN_ABSENT`))_
- **A new export in `src/data/` is reachable from a case in the suite file that exercises its module.** Which file that is is owned by `.claude/context/conventions.md` (`## The testing bar`), and the name a suite file takes by `.claude/CLAUDE.md` (`## File naming conventions`); this layer adds no requirement of its own about where the cases live. **What those cases must cover is owned by `.claude/context/conventions.md` (`## The testing bar`)** — the rejection cases a new guard clause owes, the raw-value assertion a write path owes, and the suite's idiom of compiled imports from `dist/` with the double installed before the module under test is imported. **What a case may reach for, and what it must spell as a literal instead, is owned by `.claude/context/tests.md` (`## What a case may reach`)**, whose answer for an absence constant is the opposite of this layer's answer for the storage key. The double's raw accessor is `getRaw` in `test/helpers/storageDouble.mjs`. _(read off: `test/notesStore.test.mjs` (`'writeAll persists what readAll then reads back'`, `'readAll drops a record whose updatedAt is not finite and keeps its siblings'`), `test/helpers/storageDouble.mjs` (`getRaw`), `.claude/context/conventions.md` (`## The testing bar`), `.claude/context/tests.md` (`## What a case may reach`))_

**Rule that holds whatever the storage medium is:** an exported signature of this layer must not name a platform type. Take and return this project's own shapes — `NoteRecord`, `string`, `void` — and keep the Web Storage API's own types out of the signature: `Storage`, `StorageEvent` and the `DOMException` a quota failure arrives as are constructed, consumed and wrapped inside the function bodies. Then moving to IndexedDB, to a file, or to a server is a swap behind a stable surface instead of an API change every caller has to follow. _(read off: `src/data/notesStore.ts` (`readAll`, `writeAll`, `StorageWriteError`))_

## One example from this repository

> Pinning arrived after notes were already in people's browsers, and the whole compatibility decision is three lines of `src/data/noteRecord.ts`: `pinned?: boolean` on the interface, `export const PINNED_WHEN_ABSENT = false` beside it, and the guard clause `candidate.pinned === undefined || typeof candidate.pinned === 'boolean'`. A required `pinned` would have made `isNoteRecord` reject every pre-pinning record, and `readAll` — which drops what fails the guard rather than throwing — would have emptied the list silently on first load. This layer names the default; `src/domain/noteMapper.ts` (`toNote`) is where it is applied. `updatedAt` is the same three lines with a different answer to *what the absence means*: `UPDATED_AT_WHEN_ABSENT` is `null`, because a note nobody has edited has no instant to report, and its guard clause carries `Number.isFinite` because the field is a number.

## Not determined

- Whether a record whose shape changes *incompatibly* is ever meant to be migrated rather than dropped — that a record is never repaired on the way in is settled (`.claude/context/conventions.md`, `## The wire surface`), and an added optional field is tolerated by construction, but nothing states what happens when an existing field's type or meaning changes: `readAll` would drop such a record and rewrite nothing. A version field on `NoteRecord`, an upgrade-on-read step in the gateway, or a rule here settles it.
- Whether concurrency across browser tabs is in scope — the gateway reads, mutates in the caller and writes the whole collection back, so a second tab's write is overwritten rather than merged, and nothing in the gateway reconciles one. Nothing in the tree says whether that is accepted or simply unreached. A stated decision here, or a listener appearing behind this gateway, settles it.
