# general review — ### 4. Claude Code's built-in protected-path placeholders can be left in a run copy after a killed session, and nothing records or states them — iteration 0

## Must Fix
1. **`.mcp.json` is described both as unnamed by any profile entry and unrecorded by any manifest, and as a profile entry the manifest records and the sweep covers** — `docs/cli.md` (§6 residual 12, **Claude Code's own placeholders: accepted, not swept.**) — "which no profile entry names" / "No manifest records them (measured: the control"
   The bullet's lead says the whole 21-path list, `.mcp.json` included, is at paths "which no profile entry names", and that "No manifest records them", labelled **measured**. Its second sub-bullet then says `.mcp.json` is one of "the profile's own entries under the sibling glob, so the manifest records those and the sweep covers them". The code agrees with the sub-bullet, not the lead:
   - `cli/src/generators/writeProtection.ts` → `copySurfacePaths` lists `.mcp.json` among the worktree-relative protected set under the sibling glob.
   - `cli/templates/scripts/autonomous-watcher.sh`, the manifest block that opens "What was absent before this session", adds `"${add_root%/}/.mcp.json"` for every `--add-dir` root, `"$worktree"` first. So the run copy's own `.mcp.json` is in the manifest whenever it was absent at launch.
   The cited source does not support the "measured" label for the manifest claim either. `harness-runs/user_reviews/fix_linux_sandbox_sibling_glob_trio_review.md` → *Session 2, the control* records the `git status` listings and nothing about any manifest's contents. Confirmed by reading those three files only; no probe was run.
   Consequences: a reader with a `.mcp.json` left in a run copy after a kill gets two contradictory answers to whether the sweep removes it. Finding 6, which records this observation in `docs/sandbox-verification.md` §5/§6 and in the upstream report, would carry the false "no manifest records them" forward as a measured fact.
   **Fix:** Exclude `.mcp.json` from the "accepted, not swept" set in the lead. For example: "…at its own protected paths in the session's cwd. All but `.mcp.json` are paths no profile entry names (`.mcp.json` is the profile's own entry; see below)." Change "No manifest records them" to "No manifest records any of them but `.mcp.json`", and label that clause **derived** from `autonomous-watcher.sh`'s manifest block and `copySurfacePaths`, not measured. Keep the **measured** label on the `git status` listings only.
