### 5. Three autonomous forks bind `<MAIN_REPO>` to a watcher environment that does not exist, with no literal-spelling rule

**Files:**
- `plugin/instructions/plan_orchestration_instructions_autonomous.md` → `## Override B — global kill switch`, the **Path:** bullet: "the engine resolves it from the watcher-supplied environment (or `git worktree list` — the main worktree is the first entry)"
- `plugin/instructions/user_review_fixes_instructions_autonomous.md` → `## Override B — global kill switch`, the **Path:** bullet: "resolve it from the watcher-supplied environment, or as the first entry of `git worktree list`"
- `plugin/instructions/user_review_fix_plan_writing_instructions_autonomous.md` → `## Safety scaffolding (delta — the core states none)`, step **1. STOP checks.**: "(resolve `<MAIN_REPO>` as the main worktree's root — the first entry of `git worktree list`)"

**The problem.** Each of these forks now pushes with `bash <MAIN_REPO>/<scripts_dir>/push-branch.sh "$REPO_ROOT"`. The push reaches the profile's excluded rule and its `allow` entry only when `<MAIN_REPO>` is spelled as the literal absolute path. A variable such as `$MAIN_REPO`, or a substitution, matches neither, so the call is refused under `dontAsk` or runs sandboxed. The other six files that carry the push say this in a `<MAIN_REPO>` `## Resolved values` row: "Spell it as a literal absolute path in the command, never through a substitution or a variable." Examples are `committer.md`, `dispatch_discipline_instructions.md` and `task_plan_writing_instructions_autonomous.md`. These three forks bind `<MAIN_REPO>` where it is first written, and carry no such rule.

Two of them point first at a "watcher-supplied environment". The watcher exports no such variable: `autonomous-watcher.sh` exports only `PATH`, `NVM_DIR`, `HARNESS_REPO_SLUG` and `HARNESS_INPUT_CHAIN`. An orchestrator following that pointer looks for `$MAIN_REPO`. If it spells the push with it, the variable is unset in a fresh Bash call and matches no profile entry. Before this branch the token only located the kill-switch file, where the wrong spelling cost little. It now decides whether the push runs where it can succeed.

**Fix.** Make the three binding sites say what the other six say. Each is one sentence.
