### 4. `docs/cli.md` still says a worktree record's files are left writable because a run's own git writes them

**File:** `docs/cli.md` → §6, the paragraph **Everything that runs outside the sandbox is write-protected on both sides** — "with the files in it left writable because a run's own git writes its `HEAD`, `index` and logs there"

This branch rewrote the rationale in the write-protection module this paragraph cites. `cli/src/generators/writeProtection.ts` → `protectedPaths` now says the records are protected file by file because "no `denyWrite` covers a whole record, because the change that measured why a run could not commit was barred from changing a protection". It adds that on Claude Code 2.1.299, macOS, the runtime keeps a record outside the session's cwd closed to sandboxed git whatever the profile says (`docs/sandbox-verification.md` G1, G2), so a run's commits go through the excluded `commit-on-branch.sh`, which writes only the record's `index`.

`docs/cli.md` still gives the old reason: the files are left writable because a run's own git writes `HEAD`, `index` and logs there. The new paragraph two above it, **Three wrappers run outside the sandbox, each in one spelling.**, now says that a sandboxed git cannot write that record at all. So the document contradicts itself, and it disagrees with the module it cites. Register row 29 assigned this paragraph to Task 9, but its rationale clause was not updated.

**Fix:** replace "with the files in it left writable because a run's own git writes its `HEAD`, `index` and logs there" with "with no entry covering the whole record — a run's commits go through the excluded `commit-on-branch.sh`, which writes only the record's `index`, because the runtime keeps a record outside the session's working directory closed to sandboxed git whatever the profile says (`docs/sandbox-verification.md` G1, G2)". Leave the rest of the sentence, from "plus the record's `commondir`, `gitdir` and `config.worktree`" onward, unchanged. This is a prose edit to a document and runs no test.
