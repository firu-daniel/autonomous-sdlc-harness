### Task 4 — Silence git's detached-HEAD advice in the `Install the pinned plugin` tag clone

**Goal:** Stop the `Install the pinned plugin` step from printing git's detached-HEAD advice ("Note: switching to '<sha>'. You are in 'detached HEAD' state …") into every job log. First establish, with a test, why `--quiet` does not already suppress it. Also make the step's upgrade-route refusal stop telling the adopter to commit only the two workflows.

**Why, as far as the plan can state it, and what the test must confirm.** `git clone --quiet` silences clone's progress output. The advice printed after a checkout of a tag is a separate message, and git gates it on the `advice.detachedHead` configuration key, not on the verbosity option. So `-c advice.detachedHead=false` on that one invocation removes it and changes nothing else. The plan could not run the reproduction here, so this cause is a claim to confirm, not a fact. The first work bullet confirms it.

**The step's `upgrade_route` literal also changes, for a different reason.** It ends "then commit both and push them to the default branch". After Task 2, the first upgrade past this release also merges new lines into the tracked `.gitignore`. An adopter who commits only the two workflows then gets a job that fails in its `Generate the job's permission profile` step on `init … changed tracked files` (story index, first `Top risks:` entry). This task owns the literal because it already edits the same step. The upgrade's printed report owns the commit set (Task 3: its `git add` names the workflows plus every in-repository file the run merged into), so the literal points at that report instead of listing paths.

**Where this task stops.** This task edits the clone line, adds a comment above it, rewrites the `upgrade_route` literal's commit clause, and adds or extends test cases. The step's refusal conditions, its `::error::` lines around `$upgrade_route` and the version check are unchanged. `docs/remote-execution.md` → "**Plugin install, and its pin.**" describes none of the advice, so no document changes with this task (story index, `## Scope register` row 21).
