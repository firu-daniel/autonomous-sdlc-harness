### Task 4 — Wire `--backend` through `args.mjs`, `run.mjs` and `arms.mjs`, leaving the flag-absent path unchanged

**Goal:** Let one runner drive either backend over the same corpora, query sets and arms, scoring both with the same `metrics.mjs` → `scoreArm`. A run that names no `--backend` takes the code path it takes today and produces the same records. This is deliverable 1 of the task prompt: *"Give it a way to drive the Python backend over the same corpora, query sets and arms … Do not reimplement the scoring … The TypeScript path through the runner must produce the same results it did before this branch."*

**Depends on:** Tasks 2 and 3. This task consumes them with these exact contracts:

- From Task 2 (`evals/docs-retrieval/backends.mjs`): `BACKENDS` (`['typescript', 'python']`) and `backendFor(label)`, which returns the label or throws `eval: unknown backend <label>; …`. `results.mjs` renders `corpus.backend`: `undefined` gives today's unlabelled block, and a string gives the `<id>@<backend>` block with that backend's provenance line.
- From Task 3 (`evals/docs-retrieval/python-backend.mjs`): `openPythonSession({ checkout, resolved })`, which resolves to `{ backend: 'python', snapshot: { files, chunks }, chunkKeys: Set<string>, warnings: string[], embedder: { id }, reranker: { id }, packageVersion, search({ query, k, mode }) → { hits: [{ ref, score }], abstained, bestRerankScore, searchMs }, close() }`.

**Where this task stops.** It does not render anything new: Task 2 owns every rendered byte. It runs no measurement of record either: the four `--out` runs are the operator's hand run (story index → **Manual setup required**), and this task verifies on stdout and on scratch copies only.
