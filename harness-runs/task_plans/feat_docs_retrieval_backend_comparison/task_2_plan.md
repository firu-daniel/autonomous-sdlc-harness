### Task 2 — Declare the backend vocabulary in `backends.mjs`, and key, label and transplant per-backend blocks in `results.mjs`

**Goal:** Let one results file carry, for one corpus, the eval branch's recorded TypeScript block, a same-session TypeScript re-run and a Python run side by side, without any of them overwriting another. Give the hand run a way to move finished blocks from its scratch copy into the document of record that keeps `results.mjs` the generated region's one writer. A block rendered for a run with no backend named is **byte-identical** to what this module renders today.

**Depends on:** Task 1. `query-log-pass.mjs` → `comparedArm` already reads its block through `readCorpusMachineHalf(text, 'self-docs')`, by marker, so a `self-docs@…` block added here cannot be read in its place.

**Where this task stops.** Nothing here runs a backend or parses a flag. **Task 4** sets `corpus.backend` on the result object `run.mjs` returns, from `--backend`. **Task 3** produces the Python session whose ids and route the provenance names. This task renders whatever `corpus.backend` holds: `undefined` means *no backend named*, and it is the only value under which today's bytes are produced.

### Targets

- `evals/docs-retrieval/backends.mjs` (new) — the backend vocabulary's one declaration.
- `evals/docs-retrieval/results.mjs` — block id, heading, provenance and machine half per backend; `transplantCorpusBlock`.
- `evals/docs-retrieval/README.md` → `## The modules` (`results.mjs` row amended, `backends.mjs` row added) and the single-sources section, today headed `## Two single sources this directory reads and never copies` and retitled by this task to `## The single sources this directory reads and never copies` (a third bullet, the heading's count dropped, its lead sentence's *"Both exist"* made *"Each exists"*). These are scope register rows 21, 25 and 26.

**Work:**

- [ ] `backends.mjs`: header with *"The rule this module exists to enforce"*: the backend set is declared once, here, and every flag check, block key and provenance line reads it, the way `arms.mjs` is the arm table's single declaration. Export `backendFor(label)`, which returns the label, refused by name against `BACKENDS` with `eval: unknown backend <label>; the backends are typescript, python`. Export `corpusBlockId(corpusId, backend)`, which returns `corpusId` when `backend === undefined` and `` `${corpusId}@${backend}` `` otherwise. The header states why an *explicit* `typescript` gets its own key: the same-session re-run must not overwrite the eval branch's recorded unlabelled block, which `## Threshold calibration`, `## The query-log pass` and `check-floor.mjs`'s floor all stand on.
- [ ] `results.mjs`: `corpusStart` / `corpusEnd` take the block id from `corpusBlockId(corpus.id, corpus.backend)` in `renderCorpusBlock` and `rewriteGeneratedRegion`. `readCorpusMachineHalf(text, blockId)` keeps its signature. With `corpus.backend` set: the heading reads `` ### Corpus `<id>` — backend `<backend>` ``, and the machine half gains `backend: <backend>` immediately after `corpus`, with `corpus` still the plain corpus id. For `python`: *`harness-docs-retrieval serve-http` over a throwaway mirror of the corpus, each arm through `POST /search` with its `mode`; latency is the server's own `search_ms` — `search_docs` alone, timed inside the Python process, excluding the per-call refresh and the HTTP hop; the connection string is not recorded*. With `corpus.backend` `undefined` every byte is today's.
- [ ] `results.mjs` → new export `transplantCorpusBlock(targetText, sourceText, blockId)`: copy the block for `blockId` (its start marker through its end marker, inclusive) from `sourceText`'s generated region into `targetText`'s, replacing a same-id block there or appending it as `rewriteGeneratedRegion` appends one. Refuse by name when either file's region markers are not each present exactly once, when the source carries no such block, or when the source block's fenced `json` does not parse (reuse `readCorpusMachineHalf` for that check). The header gains one sentence: a transplanted block is bytes this module rendered in an earlier pass, so the region still has exactly one writer.

**Deviations from plan:**

- The per-backend provenance bullets live in `results.mjs` → `BACKEND_ROUTES`, which is checked against `BACKENDS` at load and refuses by name a backend with no route, as `arms.mjs` refuses a mode with no letter. The plan named the bullet texts but not where they are keyed.
- `renderCorpusTable` (the stdout view a run with no `--out` prints) uses the same backend-aware heading as the block, so the two views of a labelled run do not disagree. With no backend named it prints today's heading.
- The README's third single-sources bullet says `args.mjs` reads `backends.mjs`, as the plan asks. That holds once Task 4 lands; in this task only `results.mjs` imports it.
