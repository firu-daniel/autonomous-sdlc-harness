### Task 1 — The sweep template removes a removed copy's per-run profile, behind the live-run re-check

**Goal:** When `cli/templates/scripts/cleanup-merged-worktrees.sh` has removed a gone branch's run copy, it deletes that run's per-run profile at `hr_run_profile_file "$slug" "$branch"` before `git branch -D`. It never deletes a profile a live run still maps to. `--dry-run` reports the same decision and deletes nothing.

**Where this task stops.** This task changes only the two **templates**. This repository's own `scripts/cleanup-merged-worktrees.sh` and `scripts/lib/harness-run-lib.sh` stay at the old bytes, and **Task 4** copies these two files there byte for byte. This task writes no test: **Task 2** adds the cases to `cli/test/cleanup-run-copies.test.mjs`, and **Task 3** the end-to-end check, against the output lines fixed below. Those lines are a wire both tasks match, so carry them byte for byte. Nothing in `autonomous-watcher.sh` changes: not `run_profile_render`, not `run_profile_check`, and not the profile's path or content.

### Targets

- `cli/templates/scripts/cleanup-merged-worktrees.sh` — the sweep: the live-run function, the profile removal, its two call sites, the header.
- `cli/templates/scripts/lib/harness-run-lib.sh` — comments only: `hr_run_profile_file`'s doc comment, and the `run-profiles/<slug>/<branch>.json` entry in the lane header's *THREE ARTIFACTS* list.

**Work:**

- [ ] **One live-run function, used twice.** Turn the `jq` filter now inline in the active-run read (`select(.value.status == "running" or … "park_loop" or … "paused")`) into one function, `live_runs <registry>`. It prints one branch per line, and prints nothing with exit 0 when the registry file is absent. It returns non-zero when a present registry cannot be read as one. The start-of-sweep read assigns `active` from it, with the same refusal lines and exit-0 fail-closed path as today. No second copy of the four statuses may remain in the file. Then, right after `main_repo` and the configuration load, set `slug="$(hr_repo_slug "$main_repo")" || slug=""`. Never read `HARNESS_REPO_SLUG`: the watcher exports that, and in job mode it holds the remote slug.
- [ ] **`profile_remove <branch>`**, a function placed beside `say_skip`. It runs these steps in order:
  1. Get `file` from `hr_run_profile_file "$slug" "$branch"`. On failure, or when `slug` is empty, print one line and return: `cleanup-merged-worktrees.sh: no run profile path for '<branch>' (hr_run_profile_file refused the repository slug or the branch) — no profile removed`, with the `[dry-run] ` prefix after the `cleanup-merged-worktrees.sh: ` part under `--dry-run`.
  2. If `[ -f "$file" ] || [ -L "$file" ]` is false, return silently. There is nothing to delete.
  3. Re-read `live_runs "$registry"`. If that fails, print `… keep run profile <file> for '<branch>' — the run registry could not be re-read` and return.
  4. For each live branch `b`, compare `hr_run_profile_file "$slug" "$b"` with `file`. On the first match, print `… keep run profile <file> for '<branch>' — the live run '<b>' uses that file` and return.
  5. Under `--dry-run`, print `cleanup-merged-worktrees.sh: [dry-run] would remove run profile <file> for '<branch>'`. Otherwise run `rm -f -- "$file"` and print `cleanup-merged-worktrees.sh: removed run profile <file> for '<branch>'`. If the `rm` fails, print `cleanup-merged-worktrees.sh: FAILED to remove run profile <file> for '<branch>' — remove it by hand`.

  The `keep` and `FAILED` lines take the same `[dry-run] ` prefix rule as step 1. Use only a single-file `rm -f`, never a recursive removal, and never remove the `<slug>` directory. Nothing in the function stops the sweep.
- [ ] **The two call sites, keyed on the copy having been removed.** In the real sweep, call `profile_remove "$branch"` only after `hr_clone_remove_var` succeeded (after its `removed clone` line) or `git worktree remove --force` succeeded (after its `removed worktree` line). Both calls come before the `git branch -D` block. Do not call it on a refusal, a `say_skip`, the `FAILED to remove worktree` branch, the `is already gone` branch, or a branch with no `worktree`. In the `--dry-run` block, call it after the `would delete branch '<branch>' and remove clone|worktree <wt>` line, only when `wt` is non-empty, and before the `continue`. So the preview and the sweep make the same profile decision for every copy the preview says it would remove.
