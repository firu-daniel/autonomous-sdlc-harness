### Task 8 — Add `grade-full-run.sh`: FR1–FR7 from the full run's branch, with `source` lines

**Goal:** `grade --full-run <branch>` grades round step 6 from the branch observation (xvi) drives by hand. It reads that branch's `harness run <branch>` runs and the committed `run-analytics.json`, row by row, on exactly what each row's **Read from** names in `docs/sandbox-verification.md` → `## 10.`. A clause whose **Read from** is a source file prints `source` with the file and symbol, and is not graded.

**Depends on:** Task 6, which owns the `grade` dispatch and calls `g12_grade_full_run <branch>` **only** for `--full-run <branch>` with a non-empty branch. Without `--full-run`, `g12_grade_full_run` is never called and Task 6 itself prints each selected (or, with no `--row`, every) FR row as `not run` with the evidence `needs --full-run <branch>`; `--full-run` combined with `--row` is a usage error (exit 1). So `g12_grade_full_run` always receives a branch, and prints all of FR1–FR7 (no row filter). Task 6 also provides `g12_run_done`, `g12_step_ran`, `g12_step_log`, `g12_artifact` and `g12_evidence`. Task 1 provides `g12_result_line` (results include `source`), and Task 2 provides `G12_ROOT`, `G12_REPO` and `G12_STATE_DIR`. The full run is **not** in the state file: it is driven by hand, and only its branch is given.
