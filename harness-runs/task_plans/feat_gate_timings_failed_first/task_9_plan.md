### Task 9 — Restructure `scripts/run-gates.sh` into gate units driven by the round library, with gate 4 writing the per-file record

**Goal:** `scripts/run-gates.sh` — this repository's own, hand-written, what `commands.test` runs — prints each gate's duration on its line, writes the round's gate record and gate 4's per-file record beside the round's log, prints the ten slowest test files, and from round 2 on runs first what failed in the previous round, stopping there when it still fails. Every gate it runs today, and the way each is graded, is unchanged.

**Depends on:** Task 6, which puts the wrapper into `scripts/run-test-suite.sh` that exports `RUN_TEST_SUITE_LABEL` and `RUN_TEST_SUITE_LOG_DIR` into this script's environment; Task 7, the reporter `scripts/lib/test-timing-reporter.mjs`, which writes the per-file record to whatever `--test-reporter-destination` names; and Task 8, `scripts/lib/gate-round-lib.sh`, whose contract this script consumes as stated there:

- a prerequisite: the sourcing script sources `scripts/lib/harness-run-lib.sh` **before** `scripts/lib/gate-round-lib.sh`, because `gr_init` validates `RUN_TEST_SUITE_LABEL` against that library's `HR_TEST_RUN_LABEL_PATTERN` and the lane directory's second-to-last segment against its `HR_TEST_RUN_LOG_SUBDIR`; the round library retypes neither value, and with either unset `gr_init` leaves `GR_LABEL` / `GR_LANE` empty (no record, an unfocused round);
- `gr_init <repo_root> <tmp_dir>`; configuration `GR_PREREQUISITES`, `GR_NARROWED_IDS`, `GR_TEST_FILE_PATTERN`, `GR_TEST_ROOT`, set by this script;
- `gr_gate_line <ok|FAIL|BLOCKED|SKIPPED> <name> <seconds> [<detail>]`, `gr_record <id> <status> <seconds>`, `gr_tests_destination`, `gr_slowest <tests_tsv> <phase>`;
- `gr_run_round <unit_fn> <id>…`, which calls `<unit_fn> <id>` with `GR_PHASE` set to `focused` or `full` (and `GR_FOCUS_FILES` for a narrowed id in `focused`), expects exactly one `gr_record` per call, prints the focus / stop / continue lines itself, and returns 1 only when it stopped early.
