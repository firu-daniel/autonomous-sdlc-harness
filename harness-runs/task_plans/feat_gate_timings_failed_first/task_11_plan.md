### Task 11 — Test the round library in `cli/test/gate-round-lib.test.mjs`: first round, still failing, now passing, unreadable record

**Goal:** Pin the round driver and its helpers, which decide what a Run gates round runs: a first round runs everything; a round whose previously failing gates and test files still fail stops early with the rest not run; a round whose previously failing ones now pass goes on to the full run; a missing or corrupt previous record runs in full. Also pin the gate-line format, the record rows, the environment validation and the slowest-files section.

**Depends on:** Task 8, `scripts/lib/gate-round-lib.sh`, whose contract this suite tests as stated there:

- Configuration `GR_PREREQUISITES` (`<prereq>:<dep>,…` entries), `GR_NARROWED_IDS`, `GR_TEST_FILE_PATTERN`, `GR_TEST_ROOT`; `gr_init <repo_root> <tmp_dir>` reads and validates `RUN_TEST_SUITE_LABEL` (against `HR_TEST_RUN_LABEL_PATTERN`) and `RUN_TEST_SUITE_LOG_DIR` (relative, no `.`/`..` segment, second-to-last segment equal to `HR_TEST_RUN_LOG_SUBDIR`, an existing directory) into `GR_LABEL` / `GR_LANE`, or leaves both empty. Both constants are owned by the run library's `THE RUN GATES LANE:` block (`cli/templates/scripts/lib/harness-run-lib.sh`, kept byte-identical in `scripts/lib/` by Task 6); the round library retypes neither, its sourcing script sources the run library first, and with either constant unset `gr_init` leaves `GR_LABEL` / `GR_LANE` empty.
- `gr_gate_line` prints `  ok    <name> (<s> s)`, `  FAIL  <name> (<detail>, <s> s)`, `  BLOCKED <name> — <detail> (<s> s)`, `  SKIPPED <name> — <detail> (<s> s)`; `gr_record <id> <status> <seconds>` appends `<phase>\t<id>\t<status>\t<seconds>` to `<GR_LANE>/<GR_LABEL>.gates.tsv`.
- `gr_previous_focus_var <id>…` reads the newest other `*.gates.tsv` (header `phase\tgate\tstatus\tseconds`, last line `end\tcomplete` or `end\tstopped`), its last phase's `FAIL` ids and, for a narrowed id, the `fail` files of `<prev label>.<phase>.tests.tsv` (header `file\tstatus\tseconds\ttests\tfailed`, last line `end`) that still exist under `<repo_root>/<GR_TEST_ROOT>`; prerequisites are added; it returns 0 only with a non-empty focus.
- `gr_run_round <unit_fn> <id>…` prints, byte-exact, `run-gates: running first what failed in <prev label>: gates <ids>; test files <files or none>`, then either `run-gates: stopped early: ran only gates <ids> and test files <files or none>, which failed in <prev label>; every other gate and test file did not run, so this round cannot pass` (record ends `end\tstopped`, returns 1) or `run-gates: everything that failed in <prev label> passed; running every other gate and the whole suite`, then runs every id whose focused row is not `ok` plus every narrowed id (record ends `end\tcomplete`, returns 0); lists joined with `, `.
- `gr_slowest <tsv> <phase>` prints its `== slowest test files (<phase> run of gate 4), … ==` heading and at most ten rows, or `== slowest test files: no per-file record (<reason>) ==`.
