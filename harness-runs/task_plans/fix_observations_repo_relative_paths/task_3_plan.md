### Task 3 — Add the machine-path check before the commit wrapper in `## Commit mechanics`

**Goal:** Before the orchestrator runs `commit-on-branch.sh` on the intake file, it checks the written file for this machine's paths with one plain, allow-listed `grep`; on a hit it rewrites the offending text by Task 2's rule and checks again, and it never commits a file that still carries one. If the check cannot run, it logs that and goes on — the step stays best-effort.
