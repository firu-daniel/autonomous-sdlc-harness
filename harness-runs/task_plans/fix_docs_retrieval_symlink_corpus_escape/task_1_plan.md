### Task 1 — Apply the physical inside-repository check in `corpus.ts`, with its own test suite

**Goal:** Make `cli/src/retrieval/corpus.ts` → `corpusFiles` refuse a candidate whose real path lies outside the repository's real root, on both routes. The routes are a walked `.md` under `docs.root` (and `docs.root` itself) and a `layers[].conventions` document. A link that resolves inside keeps working under its own path. Ship the module's first direct test suite with the change.

**Where this layer stops.** This task defines the contract in TypeScript: the warning texts, their order, the lexical spelling kept in `files`, and the fallbacks. The Python port is **Task 2's** (`docs-retrieval-service/src/harness_docs_retrieval/corpus.py`), and it reproduces the strings below byte for byte. The bridge sub-command and the cross-backend parity case are **Task 3's**, and Task 3 imports this task's compiled `cli/dist/retrieval/corpus.js`, so `corpusFiles`'s signature and its `CorpusFiles` shape (`{ files, warnings }`) do not change. The prose in `docs/retrieval.md` is **Task 4's**. `cli/src/core/paths.ts` → `insideRepo` is **not** edited: the write engine, `detect/signals.ts` and `init` call it as the lexical check its header documents.

### Targets

- `cli/src/retrieval/corpus.ts`: the physical check, and its module header.
- `cli/test/docs-retrieval-corpus.test.mjs` (new): direct coverage of `corpusFiles` over symlinked fixtures. `.claude/context/conventions.md` → `## The testing bar` requires a test file to open with the rule it enforces.

**Work:**

- [ ] **The real root and the physical predicate** (`corpus.ts`). Compute the repository's real root **once** per `corpusFiles` call: `realpathSync(repoRoot)` (the JS `realpathSync`, **not** `realpathSync.native`, so it resolves one component at a time with `readlink` and folds no case, as Python's `os.path.realpath` does). On a throw, fall back to `resolve(repoRoot)`. Add a module-local helper, for example `physicallyInside(realRoot, candidate): boolean | undefined`. It returns `insideRepo(realRoot, realpathSync(candidate))`, or `undefined` when `realpathSync` throws. Import `realpathSync` and `resolve` from `node:fs` / `node:path`, and do not add a second copy of `insideRepo`'s arithmetic.
- [ ] **The `docs.root` route.** Keep the existing lexical check and the existing is-a-directory check, in that order. Then, if `physicallyInside(realRoot, full)` is not `true`, push the **existing** text `` `docs.root ${dir} resolves outside the repository and was skipped` `` and do not walk. Otherwise walk as today, then check every candidate the walk collected, symlink or not. A candidate that `physicallyInside` answers `false` for is dropped, and the walk adds the **new** warning `` `docs.root file ${rel} resolves outside the repository and was skipped` ``, where `rel` is `toRepoRelative(repoRoot, candidate)`, the lexical forward-slashed spelling `files` uses. A candidate it answers `undefined` for is dropped silently, as a dangling link is today. Sort these walk warnings by `rel` with the same `a < b ? -1 : a > b ? 1 : 0` comparator the `files` sort uses, and append them **before** the conventions loop runs. `markdownUnder` stays a lexical collector: a symlinked directory is still not descended into, and a dangling link is still dropped by its `statSync` test.
- [ ] **The conventions route.** Keep the existing lexical check, then the existing is-a-file check. Then, if `physicallyInside(realRoot, full)` is `false`, push the **existing** text `` `conventions document ${path} of layer ${layer.name} resolves outside the repository and was skipped` ``. If it is `undefined`, push the existing `` `conventions document ${path} of layer ${layer.name} is missing and was skipped` ``. Otherwise keep the document under its lexical path. Every kept path in `files` is still the link's own repo-relative spelling, never the resolved target's.
- [ ] **The module header** (`corpus.ts`). Amend it in the same edit (`.claude/context/cli.md` → `## What "done" means here`, the last bullet). State that a path is checked both lexically and **physically**, against the repository's real root, so a symlink whose target lies outside is skipped with a warning while one resolving inside is kept under its own path. State that walk warnings are sorted so their order does not depend on directory order. Record the residual: the check runs at enumeration, and a link retargeted before the read is not checked again. Update `markdownUnder`'s doc comment if it still implies a symlinked file is accepted unconditionally.
- [ ] **The test suite** (`cli/test/docs-retrieval-corpus.test.mjs`, new). It imports `corpusFiles` from `../dist/retrieval/corpus.js`. Each case builds its tree with `symlink` under `await mkdtemp(join(tmpdir(), 'harness-corpus-'))`, never inside this checkout, and removes it in `t.after` with an in-process `rm(…, { recursive: true, force: true })`. It builds no environment from `process.env`. The cases, each asserting `files` and `warnings` whole with `assert.deepEqual`:
  - (a) `docs/linked.md` → a file outside the repository is absent from `files`, with `docs.root file docs/linked.md resolves outside the repository and was skipped`.
  - (b) `docs/linked.md` → `shared/target.md` inside the repository is kept as `docs/linked.md`, with no warning.
  - (c) A conventions document symlinked outside takes the existing `resolves outside` text, and one symlinked inside is kept.
  - (d) A `docs.root` that is itself a symlink to an outside directory takes the existing `docs.root docs resolves outside the repository and was skipped` and contributes no file.
  - (e) The repository root is passed through an **alias symlink** (`alias` → the repository directory, made explicitly so the case holds on Linux as well as macOS), and the in-repository link of (b) is still kept.
  - (f) Two escaping links, `docs/z.md` and `docs/B.md`, yield their two warnings in code-unit order (`docs/B.md` first), and a dangling link still yields neither a file nor a warning.

  Open the file with a header stating the rule it enforces: a corpus candidate is admitted only when it lies inside the repository both as spelled and after symlink resolution.
