### Task 6 — Arm A's harness, its agent-task text and its transcript scorer — built, never run

**Goal:** Build everything arm A needs — the task text a headless index-first agent is given, the script that would invoke it under a read-only tool set, and the scorer that turns what it returns into the same metrics arms B–E report — and run **none** of it. No `claude -p` call is made on this branch.

**Depends on:** Task 2, which committed the `fixture-catalog` corpus and its own `INDEX.md` under `evals/docs-retrieval/corpora/fixture-catalog/docs/` — arm A navigates from that index, and it is the only corpus arm A is defined over, because this repository's `docs/` has no `INDEX.md`. Task 4, whose `evals/docs-retrieval/metrics.mjs` exports `scoreArm(records, queries, { kValues })` over records of `{ id, arm, hits: [{ ref, score }], abstained, durationMs }` and whose `evals/docs-retrieval/results.mjs` renders arm A's row; and whose `docs/retrieval-eval-results.md` carries an empty `## Arm A — awaiting a hand run` section below its `<!-- eval:generated:end -->` marker, which this task fills.

**Why nothing here runs.** Arm A needs a nested `claude -p` subprocess, and `.claude/settings.autonomous.json` carries no `Bash(claude:*)` entry; per that profile's own `_README` a tool call matching neither `allow` nor `deny` **stalls in print mode rather than prompting**, so an unattended attempt hangs the run instead of reporting a refusal. The `scripts/scratch-run.sh` route to it is technically open and is **declined on purpose**: it would put an unsupervised nested agent session, with its own auth and no token cap, inside an unattended run to take a measurement. Do not add a `claude` grant, do not route arm A through `scratch-run.sh`, and do not drop the arm. One structural property makes the fence self-enforcing and is worth keeping: `evals/docs-retrieval/arm-a/run-arm-a.sh` sits **outside** the configured `scriptsDir`, and the script-allowlist guard requires every `.sh` token in a command to resolve under that directory — so no agent can invoke this file, by construction.
