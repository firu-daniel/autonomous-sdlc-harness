**Goal:** On `ubuntu-24.04` and `ubuntu-26.04` alike, the rendered `run` job's install step leaves bwrap's children able to create a user namespace that carries capabilities, or fails the job before any session starts. This is the task prompt's goal 1, delivered in the template every adopter receives.
