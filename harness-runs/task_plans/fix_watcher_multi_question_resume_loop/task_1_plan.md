### Task 1 — Watcher: resume a park only when fully answered, and archive exactly the consumed set

**Goal:** Make `cli/templates/scripts/autonomous-watcher.sh` treat a park as a unit: resume a parked run only when every top-level question file has its answer, record every answered index it resumes for, name all of them in the resume prompt, and archive exactly that set when the resumed session exits — so a pair the resumed engine already read can never trigger a later resume, and a pair that arrived during the session is never archived unread.

**Where this task stops.** This task changes the resume selection, the resume prompt, the archival and the parked classification. It adds **no** loop guard, no new registry status and no tunable — Task 2 builds the guard on top of this file and `**Depends on:**` this task. The engine-side wording that consumes the named answers is Task 7's (`## Override 2 — resumability` case (a)); this task defines the prompt text that wording must match, restated below. This repository's own `scripts/autonomous-watcher.sh` copy is Task 13's.

### Targets

- `cli/templates/scripts/autonomous-watcher.sh` — `resume_parked_run`, `spawn_engine`, `classify_run_exit`, `archive_answered_pair`'s doc comment, the registry field documentation above `registry_init`, the `RESUME-ON-ANSWER` comment block, and the header's REPRO `a resume` entry.
