### Task 4 — Warn in `task-offer-rules` when the fence's script or its allow rule is missing

**Goal:** `doctor` reports the two silent ways the moved opt-out check can lose the offer: the fence names the script and the script is not in `<scriptsDir>`, or the fence names it and `.claude/settings.json` does not allow-list it. Settled from what `doctor` already checks: `task-offer-rules` already reads `.claude/CLAUDE.md` to grade the fence and its rules file, and `plugin-wiring` already reads `.claude/settings.json`; the rule exists only for the fence, so the fence's own check grades it.

**Depends on:** Task 1 — `TASK_OFFER_CHECK_SCRIPT_NAME`, `taskOfferCheckInvocation(config)` (`bash <scriptsDir>/task-offer-check.sh`), `taskOfferCheckRule(config)` (`Bash(<that>)`) and the existing `outerLoopScriptPath(repoRoot, config, relativePath)`, all from `cli/src/generators/outerLoopScripts.ts`.
