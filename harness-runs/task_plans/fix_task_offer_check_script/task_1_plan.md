### Task 1 — Ship `task-offer-check.sh` as an outer-loop script, with its table row and the one invocation/rule producer

**Goal:** Add the script that owns the change-request fence's opt-out answer, `cli/templates/scripts/task-offer-check.sh`, as one row of the shipped outer-loop table, and give the CLI a single producer for its invocation and its exact `Bash(…)` allow rule, so the fence (Task 2), the settings merge (Task 3) and `doctor` (Task 4) all read one string.

**Where this task stops.** It ships the script, its row, the two helpers and the copy/idempotence coverage. It does **not** touch the fence text (Task 2), `.claude/settings.json` (Task 3) or `doctor` (Task 4), and it does not write the script's behavioural layout tests — Task 5 rewrites `cli/test/task-offer-fence.test.mjs` to run this script in every layout. It does not touch `cli/templates/scripts/lib/harness-run-lib.sh` in any way.

**Work:**

- [ ] **`task-offer-check.sh`.** `#!/usr/bin/env bash`, `set -u` and no `set -e` (an aborted decision must still be silence; argue it in the header), bash 3.2-compatible, no `mktemp`, no `HARNESS_MAIN_REPO` read. Source the library from its own location, `. "$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/lib/harness-run-lib.sh"`, exiting 1 silently when that fails. Decision, in order — every refusal exits 1 printing nothing on stdout or stderr:
  1. Any argument → one usage line on stderr, exit 2.
  2. `top` = `hr_repo_root "$PWD"` (the session's checkout, judged from the working directory, never from the script's own location).
  3. If `"$top/.git/objects/info/alternates"` does **not** exist (`[ ! -e … ]`, exactly the one-liner's test): `main` = `hr_main_repo "$top"` — the first `worktree ` line of `git worktree list --porcelain`, today's answer for a main checkout, a linked worktree and a plain repository. No `jq` on this arm.
  4. Otherwise the clone arm, with no fallback to step 3: `toc_alternates_candidate` (a function of this script) reads the file, requires **exactly one line** counted as `sed -n '$='` counts them (a final line without a newline counts; an empty file or a second line, empty or not, refuses), requires that line to match the `case` pattern `/*/.git/objects`, and yields the line with `/.git/objects` removed. Then `main` = `hr_copy_sync_main_of "$candidate"` (canonical; `.git` a real directory with no `commondir`); `top_c` = `top` made physical (`cd -P`); refuse when `main` equals `top_c` or `top_c/.git` is not a real directory; then `hr_clone_target_check_var "$main" "$top_c" ""` must return 0 (registry record `copy_kind` `clone` at this path, `hr_worktree_dir` derivation, no planted trust files, `alternates` naming `<main>/.git/objects`, the clone configuration allow-list; `jq` reached here only).
  5. Refuse when `main` is empty or `"$main/.claude/harness-no-offer"` exists (`-e`, presence only, never read); otherwise `printf '%s\n' "$main"` and exit 0.

State: the exit map (0 offer and the path on stdout; 1 every no-offer outcome, silent; 2 bad usage); who runs it (an interactive session's fence, `.claude/CLAUDE.md` → `## Where a change request runs`, item 4, bare from the checkout root, matched by the exact `Bash(…)` rule in `.claude/settings.json`); that it judges the working directory's checkout; which library functions it reuses and that `toc_alternates_candidate` is its own; that it reads no `HARNESS_MAIN_REPO`; that `jq` is reached on the clone arm only. **The accepted stricter case** (`harness-runs/clarifications/fix_task_offer_check_script/answered/answer_1.md`, Q2 (a)): through `hr_clone_target_check_var` it also refuses a clone with a planted `commondir`, `config.worktree` or `objects/info/http-alternates`, non-directory `objects`, or a `.git/config` key outside the clone allow-list (a hand-run `git push -u`'s `branch.<name>.*`), where today's one-liner offered; and the Linux case where it bites today — *until #219 lands, a Linux run copy can carry leftover `commondir` / `http-alternates` placeholders after a killed session and a `config.worktree` (cause unknown), so the fence is silent there, as the wrappers already refuse that copy.* Also: a candidate whose `.git` is a symbolic link is refused, and the printed path is the canonical main checkout rather than the raw `alternates` prefix — identical in every layout the fence test covers. **Two settled states:** a checkout whose fence names this script but which predates it gets bash's "No such file or directory", a non-zero exit and empty stdout — silence; a copy older than the template needs nothing, since the exit contract is the whole interface and `init --force` (after a `.bak`) is the upgrade route, as for every outer-loop script.
