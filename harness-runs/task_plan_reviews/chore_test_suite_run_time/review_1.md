## Must Fix

1. **`task_1_plan.md`: the equivalence test compares commit object ids that depend on the clock, so it fails intermittently**
   The last Work bullet (`cli/test/fixture-template.test.mjs`) says to assert that a copied fixture and a freshly seeded one give equal answers for ``git for-each-ref --format=%(refname) %(objectname)``. It also says that `git ls-remote origin` must list "the same branch at the same object id". But the origin commit is made by `seedOrigin` in `cli/test/helpers/fixture.mjs` as `runGit(dir, ['commit-tree', tree, '-m', 'origin seed'])`. `ISOLATED_ENV` pins no `GIT_AUTHOR_DATE` / `GIT_COMMITTER_DATE`, so the commit's author and committer timestamps (to the second) are part of its object id. The template is seeded when the test's first `createFixture` runs. The comparison repository is seeded by a later `seedRepository` call, about 100–200 ms after that. Whenever the two seedings fall in different wall-clock seconds, the object ids differ and the test goes red. This is exactly the intermittent failure the story index's first `Top risks:` entry and the task prompt's Acceptance 2 (*"three consecutive runs are green, so no concurrency flake is introduced"*) rule out. The test would also fail more often under the load that Tasks 2–4 add.
   **Fix:** In `task_1_plan.md`, drop object-id equality from both comparisons. Instead, compare `%(refname)` alone for `for-each-ref` and the ref name alone for `ls-remote`. Then assert the property that the copy must actually preserve. First, the local `refs/remotes/origin/<branch>` and the origin's `refs/heads/<branch>` name the **same** object *within each repository*. Second, that object is a commit whose tree is the empty tree (`git rev-parse <ref>^{tree}` equals `git hash-object -t tree /dev/null`) and whose subject is `origin seed`, in both the copy and the freshly seeded repository. An alternative is to pin `GIT_AUTHOR_DATE`/`GIT_COMMITTER_DATE` in `seedRepository`. Choose it only if the plan argues it, because it changes the environment every fixture's seed runs under. Leave the `rev-parse --verify --quiet HEAD` unborn check, the `symbolic-ref`, the `config` checks and the "own sibling origin" check as they are.
