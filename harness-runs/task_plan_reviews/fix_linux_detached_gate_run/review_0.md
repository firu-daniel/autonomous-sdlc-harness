   (b) Add to `### Targets` every test that runs the watcher's `job` entry and is affected, at least `cli/test/watcher-remote-job.test.mjs`, `cli/test/watcher-stall-reset-payloads.test.mjs` and case (5) of `cli/test/watcher-placeholder-host.test.mjs`.    (c) Derive that list from a stated grep, for example `git grep -l 'HARNESS_JOB_MODE' -- cli/test`, rather than from this finding, and add a `**Verification:**` bullet that reruns the grep.
   Keep `**Work:**` at 5 bullets: fold this into the existing **Tests** bullet.
