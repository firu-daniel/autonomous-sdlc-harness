1. **The per-command scratch directory is named by the raw branch, so it is left behind or cannot be removed for valid branch names** — `task_8_plan.md`, `task_9_plan.md` (and the interface stated in `task_7_plan.md`, restated in `task_10_plan.md` / `task_12_plan.md`).
   The plan names each directory `<state_dir>/scratch/<command>-<branch>/`, built from `<branch>` verbatim. `remote-run.sh` accepts any branch that does not start with `-` (`cli/templates/scripts/remote-run.sh` → `valid_branch`), and branch-pause, branch-resume, branch-answer and branch-user-review take their prefix from a branch the user names. Two shapes break the planned guarantee:
   - **A branch containing `/`**, such as `feat/recent_searches_panel` (the shape the harness's own sample branch uses). `mkdir -p <state_dir>/scratch/branch-pause-feat/recent_searches_panel` creates two directory levels. `discard` removes only the leaf, so an empty `branch-pause-feat/` directory is left on every invocation. The task prompt asks to keep the guarantee that nothing is left behind (*"Keep the guarantee that nothing is left behind."*).
   - **A branch containing a character outside `A-Za-z0-9._/-`** (git allows `+`, `@`, `#`, `,` and others). Task 6's `hr_scratch_path_var` refuses it as `charset`, so `discard` exits 2 and leaves the directory the command just created. The next invocation then finds that directory, stops as a "leftover", and names `discard` as the remedy. That same `discard` refuses the same path, so the command is stuck until someone removes the directory by hand. This is the lessons ledger's *"removes it on every exit path, success and failure alike"* rule, broken for a class of valid inputs.
   **Fix:** Name each directory from a fold of the branch that always lands in a single path segment of the accepted character class. For example: `<command>-<branch with every character outside A-Za-z0-9._- replaced by _>`, stated once in Task 7's interface and its `scratch/README.md` paragraph. Use that folded name in every create, fetch, leftover-check and `discard` sentence in `task_8_plan.md` and `task_9_plan.md`, and in Task 10's **What each local command does…** wording and Task 12's leg (c) pass condition. Add a `task_7_plan.md` test case that runs `discard` on a folded directory for a slash-bearing branch, to show nothing remains under `scratch/` afterwards. A fold collision between two branches is safe, because the leftover check then stops the command; say so in the same place.
