5. **Cross-task interface — `sp_extra_clone` cannot produce Task 7's behind-the-default fixtures** — per-task files `task_4_plan.md` and `task_7_plan.md`.
   Task 4 defines `sp_extra_clone <branch> [--no-bootstrap]` as cutting a clone through `create-worktree.sh`. In default mode, that script cuts `refs/heads/<branch>` *"at the default branch's commit AS ORIGIN REPORTS IT"*. It refuses when *"a local branch '$branch' already exists"* (`scripts/create-worktree.sh`, its default-mode header and the `show-ref` refusal). Task 7's fixture builder needs branches cut *"off `origin/<default>~N`"*, with zero or one commits of their own, that already exist before the clone is made. Only `create-worktree.sh --existing` checks out such a branch, and Task 4's API has no existing-branch arm. Task 7 also says the fixture is built "through the clone's own git" before `sp_extra_clone` runs. No clone exists at that point, and a branch made in another clone is not a local ref `create-worktree.sh` sees. As planned, R1–R3 cannot be built.
   **Fix:** In Task 4, give `sp_extra_clone` an `--existing` arm that calls `create-worktree.sh --existing <branch>` and registers the clone and branch the same way. In Task 7, state the fixture route exactly: create `refs/heads/<fixture>` in `<main>` at `origin/<default>~N`, plus the fixture's own commit for (b)/(c), from a terminal-equivalent git call; `sp_track_branch` it; then call `sp_extra_clone <fixture> --existing`. Restate the new signature on both sides.

6. **Infeasible step — L1's `-sbxdash` clone cannot be cut, and no route is given** — per-task file `task_8_plan.md`.
   L1 asks for *"a throwaway branch `-sbxdash` and its clone"*. A clone whose checked-out branch differs from its registry record could be refused by `push-branch.sh` for the mismatch rather than for the dash (`push-branch.sh: branch '…' starts with '-'`), and L1 would then pass on the wrong evidence.
   **Fix:** State L1's route on the clone layout. For example: in a registered probe clone, check out `-sbxdash` from a terminal-equivalent `git` call, and track that branch and the switch back. State that L1 passes only when the refusal line is the dash refusal `push-branch.sh: branch '-sbxdash' starts with '-'`, with any other refusal recorded as `fail` and quoted. Otherwise, if no route exists, record L1 as unreachable on the clone layout with that reason in the leg line and in the register row.
