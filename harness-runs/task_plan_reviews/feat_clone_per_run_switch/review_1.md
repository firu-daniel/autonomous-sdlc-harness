## Must Fix

1. **`task_7_plan.md` — a failure after a successful creation push leaves the pushed remote branch behind.**
   Task 7 adds a step after the push: *"Then sync the pushed tip's remote-tracking ref out to the clone: `hr_copy_sync_out_var … "refs/remotes/origin/$branch" ""` … A failed sync-out is a failure exit after the branch exists, so the rollback below covers it (exit `2`, naming the step)."* The rollback removes the clone, the **local** branch, the registry record and the registry directory. It never removes `refs/heads/<branch>` on `origin`, which this run's push has just created. Today the push is the script's last step, so no failure exit can follow it. This task creates the first one.
   - This breaks goal 1 (*"It removes everything it created on every failure exit after the branch exists, the branch included"*).
   - It repeats a ledger lesson. `harness-runs/lessons.md` → `## Remote and branch-scoped operations`: *"A script that creates a temporary working copy or branch removes it on every exit path, success and failure alike, and never removes one it did not create."*
   - It also strands a retry: the next default-mode run for the same branch meets a branch that already exists on origin.

   **Fix:** In `task_7_plan.md`, settle the post-push failure explicitly. Pick one:
   - **(a) Delete the remote branch in the rollback.** Add a rollback step that runs only when this run's push landed. It deletes the remote branch with a lease on the pushed tip, from the main checkout: `git -C "$main_repo" push --force-with-lease="refs/heads/$branch:<pushed tip>" origin ":refs/heads/$branch"`. A failed delete prints one line naming what is left and the command that clears it, like the other undo steps.
   - **(b) Make the mirror sync-out non-fatal.** Report it as one warning line and exit `0`, and say what the run sees until `push-branch.sh`'s next push syncs the mirror. Task 28's read then errors on a missing `origin/<branch>` and reports "nothing was pushed".

   Restate the chosen behaviour in `task_8_plan.md` → **Depends on** (*"A failed sync-out is exit `2` with the rollback"*), add a case there that forces the mirror sync-out to fail and asserts the outcome (including `git ls-remote origin <b>`), and update Task 7's exit map and header bullets to match.
