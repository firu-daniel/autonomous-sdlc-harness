# Architecture review — iteration 0

## Must Fix

1. **`gate-round-lib.sh` retypes the Run gates lane constants the run library owns** — `task_8_plan.md` (and, as a consequence, `task_9_plan.md` and `task_11_plan.md`). Rule source: `.claude/context/conventions.md` → `### Where a new responsibility goes` (*"A responsibility that already has a home does not get a second one"*; *"Before adding a copy of anything, grep for it"*) and `## Configuration is the source of truth, and it is read at run time` (*"The shared constants have owners, and a value is imported from its owner rather than retyped"*).
   Task 8's `gr_init` validates `RUN_TEST_SUITE_LABEL` against a literal `^[A-Za-z0-9][A-Za-z0-9._-]*$` and `RUN_TEST_SUITE_LOG_DIR` against a literal second-to-last segment `test_run_logs`. Both values already have an owner: `scripts/lib/harness-run-lib.sh` (copy of `cli/templates/scripts/lib/harness-run-lib.sh`) → the `THE RUN GATES LANE:` block declares `HR_TEST_RUN_LABEL_PATTERN='^[A-Za-z0-9][A-Za-z0-9._-]*$'` and `HR_TEST_RUN_LOG_SUBDIR='test_run_logs'`, and that block's own comment states that its callers *"take all four from here and must agree on them: a drift makes … read the wrong lane"*. The plan creates a second, drift-prone copy of both values in a new file, so a later change to the lane's label set or directory name in the run library would silently make `gr_init` reject every lane and run every round unfocused with no record, with no compile error and no failing test.
   **Fix:** In `task_8_plan.md`, state that `gate-round-lib.sh` defines no label pattern and no lane-directory name of its own: `gr_init` validates against `HR_TEST_RUN_LABEL_PATTERN` and `HR_TEST_RUN_LOG_SUBDIR`, and the library's header names `scripts/lib/harness-run-lib.sh` as a prerequisite its sourcing script must source first (and that an unset value makes `gr_init` leave `GR_LABEL` / `GR_LANE` empty — the no-record outcome, never a guess). Update the Verification bullet to grep that neither literal appears in `scripts/lib/gate-round-lib.sh`. In `task_9_plan.md`, add sourcing `scripts/lib/harness-run-lib.sh` (by a `${BASH_SOURCE[0]}`-derived path) before `gate-round-lib.sh`, and update the Depends-on contract restatement. In `task_11_plan.md`, have the harness copy both libraries and source the run library before `gate-round-lib.sh`, and update the restated `gr_init` contract to cite the two `HR_TEST_RUN_*` names instead of the retyped literals. Restate the decision in the story index's `## Context` seam bullet so every task carries it.
