After Task 11 the watcher emits those names through the library, and a rename of either constant would miss this copy. `### Targets` names neither `cli/src/remote/githubActions.ts` nor the library's header.

   - **(a)** Add `cli/templates/scripts/lib/harness-run-lib.sh` to the header's **Shell and YAML mirrors** list, and amend the watcher sentence to say it spells none of these names itself and reaches the route text only through the library's producers. Also amend the *"no function spells one"* sentence in `THE REMOTE STATE BUNDLE` if the new variables sit there.
   - **(b)** Make the producers take the workflow file and artifact names as arguments, supplied by callers that already hold the declared mirrors. The watcher holds none, so (a) is the smaller change.

   Either way, add a `**Verification:**` grep showing the mirror declaration in both headers.
