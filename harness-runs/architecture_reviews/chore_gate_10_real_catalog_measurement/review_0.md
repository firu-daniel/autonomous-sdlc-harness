## Should Fix

1. **Leg (i)'s 128 s figure has no file of record and is written into two documents with no cross-citation** — `task_2_plan.md` line 5 (*"the two numbers this task may name are … leg (i)'s 128 s setup time, which is a figure the results file does not own"*) and work item 1, and `task_3_plan.md` work item 3 (*"attach leg (i)'s bandwidth caveat: cold-cache elapsed time is 128 s"*). The branch's whole design is single-source — `docs/retrieval-eval-results.md` → `## Cold build and index size` owns every figure and every other site cites it — and `.claude/context/conventions.md` → `### Where a new responsibility goes` states generally that *"A responsibility that already has a home does not get a second one"*, with `## Registries and dispatch tables` carrying the same principle (*"each is a single source with no second list beside it"*). Leg (i) is the one measured figure the plan leaves ownerless, so the 128 s and its route-dependent-throughput caveat will exist in two files and drift. **Fix:** name one owner for leg (i)'s figures — `docs/retrieval.md` → `## Measured, and how` item (d) is the natural one, since Task 3 already cites item (d) as the fuller record — and change `task_3_plan.md` work item 3 so `docs/development.md` **cites** item (d) for the 128 s and the bandwidth caveat rather than restating them.

2. **Task 2 risks publishing a second copy of a set the `plugin` layer owns** — `task_2_plan.md` work item 3: *"Derive the list of agents holding `mcp__harness-docs__search_docs` from the `tools:` allowlists under `plugin/agents/`"*. The derivation itself is correct and is evidence-gathering across a boundary the conventions allow (`## The layers`: the two halves are *"coupled by contract, not by import"*, and prose citation is the sanctioned form). The risk is in what gets written: if the enumerated grant list lands in `docs/retrieval.md`, that list becomes a second home for a set whose single source is the agents' own frontmatter, and it goes stale the next time an agent is added or loses the grant — the drift `.claude/context/conventions.md` → *"Before adding a copy of anything, grep for it"* exists to prevent. **Fix:** state in that work item that the derived list is **evidence, not output** — the document publishes the conclusion (whether a worktree reaching planning can fail to query) and the two named structural cases (`docs-writer`, `docs-reviewer` under the docs-catalog engine), and never an enumeration of which agents hold the grant.
