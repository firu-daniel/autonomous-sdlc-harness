This violates `.claude/context/cli.md` → `## What "done" means here`: *"A reviewer holds a change to its module's own header. The plan's "Amend the module header" instruction lists what to add: the third owned thing, why the rule sits in the committed file, and choice 3's consequence. It does not mention this sentence, so an implementer who follows the list exactly leaves a header that now misstates the module.
   **Fix:** In `task_3_plan.md` → the `projectSettings.ts` Work bullet's "**Amend the module header**" sentence, add a clause directing the implementer to rewrite the closing *"Nothing here touches the filesystem beyond reading this package's own manifest"* sentence.
