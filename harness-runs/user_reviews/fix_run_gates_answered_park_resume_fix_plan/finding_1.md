### 1. `test-fix-plan-writer` lost two definitions it acts on when it was trimmed to hold its word count

**File:** `plugin/agents/test-fix-plan-writer.md` (`## Process`, steps 1 and 2) — "The test section is present even when the typecheck failed." and "*new this round* (a likely regression) or *persisting*"

**Problem.** To keep the definition at its word count while adding answer mode, the branch shortened existing text (base `61ab408d` → `HEAD`; the file went from 2,315 to 2,313 words, so it has 2 words of headroom). Two of the removed clauses were edge cases the agent acts on, which `.claude/context/plugin.md` → `## Writing agent prose` ("Keep every edge case.") forbids dropping.

- **Step 2, *new this round*.** Before the branch it read: *new this round* — absent from the previous round's log, so a likely regression from the previous round's fix — or *persisting*. It now reads *new this round* (a likely regression). The prompt's `Earlier logs:` can name several logs, so without the definition the agent has to guess which earlier log to compare against. Take a failure that is in round 1, gone in round 2 and back in round 3. Under the old definition it is *new this round*, a regression from round 2's fix. Under the shortened one it could also be read as *persisting*. The agent writes this class into `## Source failures` and into every finding's diagnosis, so the rule is one it acts on.
- **Step 1, the order and closing of the sections.** Before the branch it read: The typecheck section opens first and closes with either its `exited` line or its `not run` line; the test section follows and is present even when the typecheck failed. Only the last clause remains. The code block above it lists the `typecheck exited` and `typecheck not run` markers on consecutive lines, as if both appear. The wrapper writes exactly one of them (`scripts/run-test-suite.sh`, the `marker "gate typecheck not run: …"` / `marker "gate typecheck exited $typecheck_status"` if/else). The agent relies on the order and on that either/or closing to assign each output line to its gate, and to know that a typecheck section with a `not run` line has no `exited` line. This one is an edge case it acts on too.
- The dropped sentence calling typecheck-section failures **static** is not restored. No reader uses that label: the per-finding file's `none — typecheck` form and `## Source failures`' "List typecheck-section failures under their gate" carry the distinction.
