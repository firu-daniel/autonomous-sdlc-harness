# test_fix_point_reviews/

One `<branch>_<gate_key>_round_<gate_round>/item_<N>/review_<i>.md` per failed unit review, holding the findings against a single implemented fix. `<N>` is the fix's position in the round's readiness list — the first entry is `item_1`, the second `item_2` — which is not necessarily the `K` its `finding_<K>.md` carries under `<state_dir>/test_fix_plans/`, because the list is sorted by ship order. Inside the item's folder, `<i>` is the next free index: immediately before each layer-reviewer dispatch the unit loop lists the folder and passes one past the highest `review_<n>.md` there, or `0` when there is none (`${CLAUDE_PLUGIN_ROOT}/instructions/unit_loop_core.md` → `## The unit loop`). A fix whose `_(layer: …)_` tag names two layers keeps both layers' files in this one folder as a single interleaved series, and no file is written over another.

A file here is written by the layer reviewer the fix's layer routed to, and read by that fix's layer implementer on the fix iteration, which is handed the `findings_file:` path its own layer's reviewer returned — not a listing of the folder, whose highest-numbered file can be the other layer's. Each file's title names its layer: `# <layer> review — <task_heading> — iteration <n>`. The reviewer creates the folder itself and only when it has findings to write, so a fix that passed on the first review leaves no folder behind.

Nothing supersedes an earlier file — the numbered set is that fix's convergence history — and the folder is committed in the fix's own commit, which stages it explicitly, so its files are tracked from that commit on. The committer leaves these files out of its test for whether the commit landed any work, so a fix whose only other change is the readiness flip is still reported as index-only (`${CLAUDE_PLUGIN_ROOT}/agents/committer.md` → `## Process`).

The mistake worth naming is reading an empty directory as a missed step. Files appear only where the flow's per-unit review is on; in a flow where it is off, fixes go straight from implementer to committer, and this directory stays empty by design.
