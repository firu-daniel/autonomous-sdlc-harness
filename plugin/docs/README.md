# docs/

**Who reads this:** someone who has arrived in this directory and needs to know which of its two documents answers their question, and why either ships **inside** the plugin rather than at the harness root.

Both are **process assets**: they describe the plugin's own loop, so they travel with it — the repository's root README frames the flow documents that way, alongside the agents, slash commands, hooks, instructions, samples and helper scripts. They are also resolved at runtime, and it is the **command** bodies that do the resolving: the `branch-*` commands cite `${CLAUDE_PLUGIN_ROOT}/docs/AUTONOMOUS_FLOW.md` by path and quote one of its steps by section name, so a renamed heading breaks a shipped command (`grep -rn "AUTONOMOUS_FLOW" plugin/` regenerates the citing set). No **agent** body cites either document, and the single instruction-body mention — in `instructions/mode_contract.md` — names `AUTONOMOUS_FLOW.md` in prose without resolving a path. Adopter-facing documentation of the CLI, the configuration and the outer loop is not here; it stays at the harness root, outside the plugin, and nothing at runtime resolves a path into it. That boundary has one operational consequence worth stating: **a document here cites a sibling plugin asset as `${CLAUDE_PLUGIN_ROOT}/<dir>/<file>` and cites anything outside the plugin by name plus where it lives**, because an installed plugin's runtime root contains only `plugin/`.

Two documents. `AUTONOMOUS_FLOW.md` is the canonical statement of the **inner loop** — the phases a run walks once it has been launched, the artifacts it writes, and what it promises when it stops. `AUTONOMOUS_FLOW_WHITEBOARD.md` is its narrative explainer, saying the same system in the order you would say it out loud to someone you are handing it to, and owning no contract of its own. The **outer loop** is neither: what turns a dropped file into a running session, the daemon's lifecycle and the machine-level usage lane are the harness repository's `docs/watcher.md`, at the repository root outside the plugin.
